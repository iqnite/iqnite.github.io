# phorb homepage

This repository contains the source code for my personal website, written with the Astro framework. It also contains the web pages of my other projects, such as the Eggsplode Recipe Maker.

To run the website locally, simply clone the repository and run `npm run dev` in your terminal.

Feel free to explore the code and customize it for your own personal website! If you have any questions or suggestions, please open an issue or submit a pull request.
